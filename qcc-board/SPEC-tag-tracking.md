# สเปก: ติดตามสายพานด้วยแท็ก RFID + กล่อง CT (สรุป 13 พ.ย. 2569)

สถานะ: **ออกแบบเสร็จ · ยังไม่ซื้อของ · ยังไม่เขียนโค้ด** (รอของครบก่อน)
โปรเจกต์ที่ต้องแก้: Apps Script **QCC Board** (`รหัส.gs`, `Device.gs`, `Box.html`) + เฟิร์มแวร์ ESP32 ใหม่ 2 ตัว (ลอก, ขัดหยาบ)

## 1. เป้าหมาย (user ระบุ)

| จุด | อยากได้ |
|---|---|
| ขัดหยาบ | เลขออเดอร์ + เวลาเริ่ม/จบ ของชุดที่ลอกส่งมา |
| ประกบ | เวลาเริ่ม/จบ ของชุดที่รับมาจากขัดหยาบ |
| เจียแต่ง | ออกจากเครื่องอบแล้ว เจียหรือยัง → เจียแล้วส่งมอบอัตโนมัติ |

หลัก: **พึ่งคนให้น้อยที่สุด** · คนที่ไว้ใจเรื่องกดได้มากที่สุดตอนนี้ = **พนักงานลอก 2 คน** (กดครบ 87–98% ตั้งแต่ปลาย ต.ค.) · ขัดหยาบเปลี่ยนคน กดเหลือ 23% (9–13 พ.ย.)

## 2. ข้อเท็จจริงหน้างานที่แบบนี้อาศัย

- สายพานวางบนพื้น เข็นด้วยรถเข็นผักที่ใช้ร่วมกัน → **ติดแท็กที่รถไม่ได้**
- สายพานมีเลขออเดอร์เขียนอยู่ ตรงกับใบแข็ง
- ใบแข็ง: ค้างที่โต๊ะลอก → **พนักงานอบเดินมาหยิบที่โต๊ะลอกทุกเส้น** (บันทึกเลขแบบเดิม) → ไปกับสายพานที่เจียแต่ง → ส่งขนส่ง
- ⇒ ช่วงที่สายพาน "ไม่มีเลขติดตัว" คือ **ขัดหยาบ + ประกบ** เท่านั้น
- ขอบสายพาน **หนีบคลิปได้**
- พนักงานลอก 2 คนใช้ **มือถือคนละเครื่อง**
- โต๊ะหัวหน้าอยู่ท้ายไลน์ (ไกลจากลอกที่สุด) → **ไม่ใช้โต๊ะหัวหน้าในวงแท็ก**
- เดาตามลำดับอย่างเดียว (ไม่มีแท็ก): ขัดหยาบหยิบตรงลำดับที่ลอกส่ง 77% (ข้อมูลตั้งแต่ 26 ต.ค.) → ผิดราว 1 ใน 4 เส้น

## 3. วงจรของแท็ก

```
[กล่องแท็กว่างที่ลอก] → ลอก: กดเริ่มในมือถือ + แตะแท็กที่เครื่องอ่านของตัวเอง + หนีบที่ขอบสายพาน
   → ขัดหยาบ: แตะแท็กก่อนขัด (CT จับเวลา)
   → ประกบ: ไม่ต้องทำอะไร (CT พัดลมจับเวลา)
   → อบ: ปลดแท็กตอนเข้าเครื่อง → รอบหน้าที่เดินมาหยิบใบแข็งที่โต๊ะลอก แตะคืนที่กล่องลอก
   → [กล่องแท็กว่างที่ลอก]
```
ตั้งแต่อบเป็นต้นไป เลขออเดอร์มาจากใบแข็งที่พนักงานอบบันทึก (ระบบเดิม) — เจียแต่งไม่ใช้แท็ก

## 4. แต่ละสถานี

| จุด | ฮาร์ดแวร์ | การทำงาน |
|---|---|---|
| ลอก | Node32S + RC522 ×2 (ตัวละคน ผูกกับมือถือแต่ละเครื่อง) + KY-016 ×2 + Piezo | ผูกแท็ก + รับแท็กคืน · แตะแท็กว่าง = ผูกกับออเดอร์ที่มือถือคนนั้นเพิ่งกดเริ่ม · แตะแท็กที่ผูกอยู่และเส้นเข้าเครื่องอบแล้ว = คืน |
| ขัดหยาบ | Node32S + RC522 + KY-016 + Piezo + CT 100A เดิม | แตะ = รู้ว่าเส้นไหน · CT = เวลาจริง · เครื่องเดินแต่ไม่มีใครแตะ → ไฟแดงกะพริบ + ปี๊บ · ยังไม่แตะ → เดาตามลำดับลอก ติดป้าย "เดา" |
| ประกบ | Node32S + CT 10A ที่พัดลม 2 ตัว | พัดลมเปิด/ดับ = เริ่ม/จบ · ชุด = ที่ขัดหยาบเพิ่งส่งมา |
| อบ | ไม่เพิ่ม (กล่องไฟเดิม) | ปลดแท็กแล้วคืนที่ลอก |
| เจียแต่ง | Node32S + SCT-013-100 | ออกจากเครื่องอบ (รู้เลขจากใบแข็ง) → เครื่องเจียเดินจบ → ส่งมอบอัตโนมัติ (เวลาส่งมอบ = เครื่องเจียหยุดครั้งล่าสุด) |

ไม่ใช้แล้ว: CYD 00001 ที่ขัดหยาบ (ว่าง) · ที่แขวนกรรไกร + ULN2003 + หลอดหน้าปัด (เป้าประกบไม่ต้องนับคน — เพิ่มทีหลังได้)

## 5. กรณีพิเศษ (user ช่วยคิด 13 พ.ย.)

| กรณี | ระบบทำ |
|---|---|
| แตะแท็กที่ยังผูกกับเส้นอื่น | บอกว่าแท็กอยู่กับออเดอร์ไหน ขั้นไหน · เส้นเก่าเข้าเครื่องอบแล้ว = ลืมคืน → ให้ผูกใหม่ · ยังไม่ถึงเครื่องอบ = ห้ามผูก ไฟแดง |
| กดเริ่มลอกแล้วไม่แตะแท็ก | มือถือคนลอกเตือนทันที "ยังไม่ได้แตะแท็ก" · เกิน 10 นาที → แจ้งหัวหน้า |
| แท็กหายระหว่างทาง | เลขออเดอร์: ยึดลอก (ต้นทาง) + ใบแข็งที่อบ (ปลายทาง) · เวลาขัด/ประกบ: จาก CT ตามลำดับ ติดป้าย "เดา" · เข้าอบเกินครึ่งวันแท็กยังไม่คืน → บอร์ดขึ้น "แท็ก NN หาย" |
| WiFi หลุด | กล่องเก็บลง flash (ไฟดับไม่หาย) พร้อมเวลาที่แตะจริง · ส่งทีหลังด้วย `evtId` แบบเดิม (`Device.gs` รับย้อนหลัง ≤ 7 วัน · ส่งซ้ำ = "บันทึกไปแล้ว") |

## 6. ข้อมูลในชีต (ใหม่)

แท็บ `Tag_Map`: `uid` · `เบอร์แท็ก` · `เลขออเดอร์` (ว่าง = แท็กว่าง) · `ผูกเมื่อ` · `ผูกโดย (มือถือ)` · `คืนเมื่อ` · `สถานะ` (ว่าง / ใช้งาน / หาย)

- ลงทะเบียนแท็กใหม่ครั้งเดียว: โหมดลงทะเบียนที่กล่องลอก แตะเรียงตามเบอร์ที่เขียนบนพวงกุญแจ
- กล่องส่งแค่ `uid + เครื่องอ่าน + เวลา + evtId` · ชีตแปลง uid → ออเดอร์เอง (ไม่เขียนเลขลงแท็ก)

| กล่อง IP65 + เคเบิลแกลนด์ PG7 + เสารอง M3 | 4 กล่อง | |

มีแล้ว: CT 100A (ห้องขัด) · CT 10A (พัดลม) · สายพ่วงแยกเส้นห้องขัด · ให้ช่างทำสายพ่วงแยกเส้นเพิ่ม 2 เส้น (ประกบ · เจียแต่ง)

## 8. ลำดับลงมือ (เมื่อของครบ)

1. แท็บ `Tag_Map` + โหมดลงทะเบียนแท็ก
2. กล่องลอก + แก้ `Box.html` หน้าลอก (ขึ้น "แตะแท็ก" หลังกดเริ่ม → "แท็ก NN ✓") — **ทดลองที่ลอกก่อน 1 สัปดาห์**
3. กล่องเจียแต่ง (ส่งมอบอัตโนมัติ) — แก้ปัญหาเส้นค้าง "รอเจียแต่ง" ได้ทันที
4. กล่องขัดหยาบ (แตะแท็ก + CT)
5. กล่องประกบ (CT พัดลม)
