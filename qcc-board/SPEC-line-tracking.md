# สเปก: จับเวลา + รู้เลขออเดอร์ทุกสถานี (สรุป 15 พ.ย. 2569 · อัปเดตรายการซื้อ)

สถานะ: **ออกแบบเสร็จ · ยังไม่ซื้อของ · ยังไม่เขียนโค้ด** (รอของครบก่อน)
โปรเจกต์ที่ต้องแก้: Apps Script **QCC Board** + เฟิร์มแวร์กล่อง CT 3 จุด

> ประวัติ: 13 พ.ย. เคยออกแบบให้ใช้แท็ก RFID หนีบสายพาน → **ยกเลิก 15 พ.ย.** (คลิปเสี่ยงหลุด/เกี่ยวเครื่องขัด, คนห้องขัดยังต้องแตะเอง)
> ตัดสินใจร่วมกับ user: ใช้ข้อมูลลอก (เชื่อถือได้) เป็นต้นทาง + เครื่องอบ (ใบแข็ง) เป็นปลายทาง + CT จับเวลาตรงกลาง

## 1. เป้าหมาย (user ระบุ)

| จุด | อยากได้ |
|---|---|
| ขัดหยาบ | เลขออเดอร์ + เวลาเริ่ม/จบ ของชุดที่ลอกส่งมา |
| ประกบ | เวลาเริ่ม/จบ ของชุดที่รับมาจากขัดหยาบ |
| เจียแต่ง | ออกจากเครื่องอบแล้ว เจียหรือยัง → เจียแล้วส่งมอบอัตโนมัติ |

## 2. ข้อเท็จจริงหน้างาน

- คนที่ไว้ใจเรื่องกดได้มากที่สุด = **พนักงานลอก 2 คน** (กดครบ 87–98% ตั้งแต่ปลาย ต.ค.) · ห้องขัดเปลี่ยนคน กดเหลือ 23% (9–13 พ.ย.) และไม่กดแอป
- สายพานวางบนพื้น เข็นด้วยรถเข็นผักที่ใช้ร่วมกัน · มีเลขออเดอร์เขียนบนสายพาน (อ่านยากบนยางดำ)
- ใบแข็ง: ค้างที่โต๊ะลอก → **พนักงานอบมาหยิบทุกเส้น** บันทึกเลขแบบเดิม → ไปกับสายพานถึงเจียแต่ง → ขนส่ง
- ห้องขัดหยิบตรงลำดับที่ลอกส่ง 77% · คลาดไม่เกิน 1 ตำแหน่ง 92% (ข้อมูลตั้งแต่ 26 ต.ค.)

## 3. หลักการ

```
ลอก (กดในมือถือ = ต้นทาง รู้เลข)
  → ขัดหยาบ: CT นับว่าขัดไปกี่เส้น → ปิดตามคิวลอก
  → ประกบ: CT พัดลม = เวลาเริ่ม/จบ ของชุดที่ขัดหยาบเพิ่งส่ง
  → อบ: ใบแข็ง = ปลายทาง รู้เลขแน่นอน (เส้นที่เข้าอบ = ผ่านขัด/ประกบแล้วแน่ ถ้าระบบนับขาด เติมสถานะให้)
  → เจียแต่ง: CT เครื่องเจียจบ → ส่งมอบอัตโนมัติ
```
เวลาที่ได้จากการเดาตามลำดับ ติดป้าย "เดา" ไว้เสมอ หัวหน้าแก้ในบอร์ดได้

## 4. แต่ละสถานี

| จุด | ฮาร์ดแวร์ | การทำงาน |
|---|---|---|
| ลอก | มือถือ 2 เครื่องเดิม | กดเหมือนเดิม |
| ขัดหยาบ | ESP32 30 ขา + CT 100A เดิม (ไม่ใช้จอ) | ช่วงเครื่องเดิน → นับเส้นที่ขัดเสร็จคร่าวๆ → ปิดตามลำดับลอก · ไอเดียเสริม (ยังทดลอง): หยอดเหรียญ 1 เหรียญ/เส้น นับด้วยเซนเซอร์ IR |
| ประกบ | จอสัมผัสยึดติดที่ (ทดลองด้วยโน้ตบุ๊กเก่าก่อน → แท็บเล็ต) + ฝึกทุกคนที่มาประกบ | **ต้องแตะเลือกเลขออเดอร์ก่อนเริ่มประกบ** และแตะ "เสร็จ" · ต้องแก้โค้ดให้ประกบกลับเป็น 2 ครั้ง (เริ่ม/เสร็จ) เพราะขัดหยาบไม่กดแล้ว เวลาเริ่มประกบเดิมมาจาก e_rough · ระยะถัดไป: CT พัดลม + ไฟเตือนเมื่อพัดลมเปิดแต่ยังไม่เลือกเลข |
| อบ | กล่องไฟเดิม + ใบแข็ง | ไม่เปลี่ยน · ใช้เป็นจุดยึดปลายทาง |
| เจียแต่ง | ESP32 30 ขา + SCT-013-100 | ออกจากเครื่องอบ → เข้ารายการ "รอเจีย" → เครื่องเจียเดินเกินเกณฑ์ขั้นต่ำ → ส่งมอบเส้นที่รอนานสุด (เวลาส่งมอบ = เครื่องเจียหยุด) |

## 5. ยังต้องตั้งเกณฑ์ / ถาม user

- ห้องขัด: ขัดทีละเส้นจนเสร็จ หรือหลายเส้นรวด · 1 เส้นขัดกี่หัว → ใช้ตั้งวิธีนับเส้นจาก CT (เก็บข้อมูล CT 1–2 สัปดาห์ เทียบกับลำดับลอกก่อนเปิดใช้จริง)
- เจียแต่ง: มีเครื่องเจียกี่ตัว เสียบจุดเดียวกันไหม · ใช้เจียงานอื่นด้วยไหม (กันส่งมอบผิด) · มีเส้นที่ไม่ต้องเจียไหม
- ประกบ: ป้ายพัดลม (W หรือ A) → จำนวนรอบที่ร้อยสาย

## 7. ลำดับลงมือ

0. รัน `StuckClose.gs` (preview → apply) เคลียร์เส้นค้างก่อน
1. กล่องเจียแต่ง (ส่งมอบอัตโนมัติ) — แก้ปัญหาเส้นค้าง "รอเจียแต่ง" ถาวร
2. ประกบ: ทดลองจอโน้ตบุ๊ก + ฝึกเลือกเลขก่อนประกบ (แก้โค้ดประกบเป็น 2 ครั้ง)
3. กล่องขัดหยาบ (ESP32 + CT) — เก็บข้อมูล 1–2 สัปดาห์ ตั้งเกณฑ์นับเส้น
4. ระยะถัดไป: ไฟเตือนพัดลมที่ประกบ · กล่องนับเหรียญ (ถ้าทดลองโถผ่าน)
