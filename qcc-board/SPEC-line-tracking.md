# สเปก: เก็บเวลาและเลขออเดอร์ไลน์ต่อหัวสายพาน (สรุปสุดท้าย 15–16 พ.ย. 2569)

สถานะ: **ตกลงแบบแล้ว · ยังไม่ซื้อของ · ยังไม่เขียนโค้ด**
โปรเจกต์ที่ต้องแก้: Apps Script **QCC Board** + เฟิร์มแวร์ CYD 00001 (ลานประกบ) + ประกอบกล่องห้องขัดเดิมกลับ
ผังการเดินงาน: https://claude.ai/artifact/AryLbmCEqkvpNmps9eYBLH (สำเนา `qcc-board/flow.html`)

## 1. เป้าหมาย

คิด **Loss Time** ให้ถูก ซึ่งต้องรู้:
1. **ประกบเริ่มและเสร็จเมื่อไหร่ ของเส้นไหน**
2. **ตอนนั้นมีเครื่องอบว่างไหม** (กล่องไฟเครื่องอบรู้อยู่แล้ว)

| สถานการณ์ | Loss |
|---|---|
| เครื่องอบเต็มทุกเครื่อง | ไม่คิด |
| เครื่องอบว่าง แต่ประกบยังไม่เสร็จ | คิด (เครื่องรอฝั่งประกบ) |
| ประกบเสร็จ เครื่องอบว่าง แต่ยังไม่ยกเข้า | คิด (เครื่องรอฝั่งอบ) |

## 2. ข้อเท็จจริงหน้างาน

- ลอกกดครบ 87–98% (ตั้งแต่ 26 ต.ค.) = คนที่ไว้ใจได้ที่สุด · ห้องขัดเปลี่ยนคน กดเหลือ 23% (9–13 พ.ย.)
- ตั้งแต่ 8 ต.ค. ประกบกดครั้งเดียว และเวลาเริ่มประกบเอามาจาก e_rough (ขัดหยาบกดจบ) → ขัดหยาบไม่กด = **เวลาเริ่มประกบหายทั้งหมด** (`Device.gs` DEV_ONE_TAP_STATIONS)
- คิวในมือถือประกบยังขึ้นครบ เพราะข้ามขัดหยาบได้ (DEV_SKIP_STATIONS)
- สายพานมีเลขออเดอร์เขียนบนตัวตลอดทาง · ใบแข็งค้างที่โต๊ะลอก → พนักงานอบมาหยิบทุกเส้น → ไปกับสายพานถึงขนส่ง
- ห้องขัด: ขัดทีละเส้น เส้นละ 2 หัว ลำดับหัวสลับไปมา · หยิบตรงลำดับลอก 77% คลาด ≤1 ตำแหน่ง 92%
- ลานประกบ: พัดลม 2 ตัว เปิดเกือบทุกครั้งที่ประกบ · คนหมุนเวียนมาช่วย
- เจียแต่ง: เครื่องเจีย 2 ตัว เสียบคนละจุด · ยังไม่เคยบังคับให้กด

## 3. แผนแต่ละสถานี

| สถานี | ทำอะไร |
|---|---|
| **ลอก** | กดในมือถือเหมือนเดิม |
| **ขัดหยาบ** | ประกอบกล่อง 30001 เดิมกลับ: บอร์ด ESP32 เดิม (กล่องอะคริลิก USB-C) + CT 100A ที่สายพ่วงเดิม · เฟิร์มแวร์ `qcc_grind_ct` (GPIO34) · นับคร่าวๆ ว่าขัดไปกี่เส้น **ไม่ต้องรู้เลขออเดอร์** |
| **ประกบ** | ① ยึดมือถือประกบไว้ที่โต๊ะ เสียบชาร์จค้าง · **ทุกคนต้องแตะเลือกเลขก่อนเริ่ม และแตะ "เสร็จ"** · ป้าย OPL ข้างจอ + ฝึกทุกคนที่อาจมาช่วย ② ไฟเตือน: CYD 00001 + CT 10A สีน้ำเงินที่ปลั๊กพ่วงพัดลม + LED 10 มม. เหลือง/เขียว + บัซเซอร์ที่ช่องลำโพง CYD |
| **อบ** | เหมือนเดิม (กล่องไฟ + ใบแข็ง) = จุดยึดเลขปลายทาง |
| **เจียแต่ง** | กดในมือถือ · ฝึกและบังคับใช้หลังรัน StuckClose (รายการบนจอจะเหลือแต่เส้นจริง) · **ไม่ทำกล่อง ไม่ปิดอัตโนมัติ** (user ตัดสิน) |

### ไฟเตือนที่ลานประกบ

ขา CYD: CT → IO35 · LED เหลือง → IO22 · LED เขียว → IO27 · บัซเซอร์ → ช่องลำโพง (IO26) · มีขาว่างพอแค่ 2 สี

| กติกา | สถานการณ์ | ไฟ |
|---|---|---|
| 1 | พัดลมเปิด แต่ไม่มีเส้นที่กำลังประกบ (กดเริ่มแล้วยังไม่กดเสร็จ) | 🟡 กะพริบ "ยังไม่ได้เลือกเลข" |
| 2 | พัดลมเปิด 2 ตัว แต่มีเส้นที่กำลังประกบแค่ 1 | 🟡 กะพริบ "มีคนประกบเพิ่ม" |
| 3 | เส้นที่กำลังประกบเกิน 1.5 × Std ประกบ (เช่น 20" Std 31 → 47 นาที) และพัดลมยังเปิด | 🟡 กะพริบ "เสร็จหรือยัง" |
| – | ทุกอย่างตรง | 🟢 เขียว |
| – | กะพริบเหลืองนานเกินเกณฑ์ | 🔔 บัซเซอร์ + เด้งเตือนมือถือประกบ (ระบบแจ้งเตือนเดิม `Alert.gs`) |

- เซิร์ฟเวอร์เป็นตัวตัดสินสีไฟ · CYD ส่งสถานะพัดลม (CT ระดับ 0/1/2 ตัว) และถามสีไฟทุก ~30 วินาที (ไฟเปลี่ยนช้าได้ ≤ ครึ่งนาที)
- **ไฟเตือนเสียบปลั๊กคนละสายกับพัดลม**
- ทดลอง 2 สัปดาห์ ถ้าคนไม่สนใจไฟ → อัปเกรดเป็นไฟทาวเวอร์ LED 12V + ULN2003 + อะแดปเตอร์ 12V (โปรแกรมเดิม · ไม่ใช้รีเลย์เพราะไฟกะพริบทำหน้าสัมผัสสึก)

## 4. งานโค้ด (ทำตามลำดับ)

1. **รัน `StuckClose.gs`** (preview → apply) เคลียร์เส้นค้าง — ปิดเส้นที่กำหนดส่ง ≤ 14 พ.ย. ด้วยเวลาจริงเฉลี่ย · ข้าม 07739 + 5 เส้นที่ไม่มีเวลาเลย (ปิดเองจากบอร์ด)
2. **ประกบกลับเป็นกด 2 ครั้ง** (เริ่ม/เสร็จ): เอา `'splice'` ออกจาก `DEV_ONE_TAP_STATIONS` ใน `Device.gs` · เช็กหน้า `Box.html` ให้ปุ่มเริ่ม/เสร็จชัด
3. **KPI ใช้เวลาเริ่มประกบจากการกดของประกบ** (`s_splice` จริง) แทน e_rough เมื่อมี · เส้นเก่าคงวิธีเดิม
4. **ไฟเตือนประกบ**: endpoint ใน `Device.gs` รับสถานะพัดลม + ตอบสีไฟตามกติกาข้อ 3 · เฟิร์มแวร์ CYD (อ่าน CT IO35, ขับ LED IO22/IO27, บัซเซอร์)
5. **ห้องขัด**: ประกอบกล่องกลับ แฟลช `qcc_grind_ct` · เก็บข้อมูล 1–2 สัปดาห์ ตั้งเกณฑ์นับเส้นจาก CT

## 6. ของที่มีแล้ว

- ห้องขัด: กล่อง IP65 30001 (แจ็ค + สาย + อะแดปเตอร์ 5V 1.5A) · บอร์ด ESP32 เดิม (กล่องอะคริลิก USB-C) · CT 100A + สายพ่วงแยกเส้น
- ลานประกบ: CYD 00001 · CT 10A สีน้ำเงิน (ร้านส่งผิด ปลั๊ก 3.5 มม.) · กล่อง IP65 เปล่า 1 ใบ · แจ็ค 3.5 มม. สำรอง 1 ตัว · บัซเซอร์
- อะไหล่: ตัวต้านทาน 10k · ตัวเก็บประจุ 10µF 50V · กล่องรับแสง LDR ที่ถอดจากเครื่องอบ (สำรอง) · ตัวแปลง USB-RS485 (ยังไม่มีงานใช้)
- โน้ตบุ๊กเก่า: เครื่องเปิดติดแต่ไม่มีจอ · จอทัชที่ถอดออกมากาวขอบเสื่อม → ไม่ใช้

## 7. ไอเดียที่ทดลองได้ (ไม่ต้องซื้อ)

- **ห้องขัด หยอดเหรียญ**: แหวนรองน็อต ~30 อัน + โถใส หยอด 1 อัน/เส้น นับเทียบกับยอดลอกทุกเย็น 1 สัปดาห์ · ถ้าได้ผลค่อยทำกล่องนับอัตโนมัติ (เซนเซอร์ IR ในท่อ + จอ OLED แสดงงานรอ · นับเฉพาะเมื่อ CT ยืนยันว่าเครื่องเดินพอ)
- **ลานประกบ แท็บเล็ต**: ถ้าทดลองด้วยมือถือได้ผล ค่อยซื้อแท็บเล็ต 8–10" + กล่องล็อกติดผนัง
