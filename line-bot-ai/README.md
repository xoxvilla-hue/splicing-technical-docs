# 🤖 เลขา AI บนบอท LINE ตัวเดิม (Gemini + Google Sheets)

เพิ่มไฟล์ใหม่ไฟล์เดียว (`AiAgent.gs`) และแก้โค้ดเดิม **1 บรรทัด**
บอทจะตอบเรื่องงานจากชีตโรงงานได้ โดยงานเดิมในกลุ่มทำงานเหมือนเดิมทุกอย่าง

## AI จะตอบเมื่อไหร่

| ที่มาของข้อความ | ผลลัพธ์ |
|---|---|
| แชทส่วนตัวจาก **คุณ** (`AI_OWNER_USER_ID`) | ใช้งานได้เต็มที่ จำบทสนทนาได้ คนในกลุ่มไม่เห็น |
| ในกลุ่มที่อนุญาต + ขึ้นต้นด้วย `@ai` · `/ถาม` · `/ai` หรือแท็กชื่อบอท | AI ตอบในกลุ่ม |
| `/id`, `/deal` | โค้ดเดิมจัดการเหมือนเดิม (AI ไม่ยุ่ง) |
| ข้อความอื่นทั้งหมด / คนอื่นทักแชทส่วนตัว | บอทเงียบ **เหมือนเดิม** |

ตัวอย่าง: `วันนี้ในแผนมีงานค้างกี่รายการ` · `@ai ออเดอร์ 07020 อยู่ขั้นไหน` · `/ถามสรุป KPI สัปดาห์นี้`
ล้างความจำของแชทนั้น: `/reset` (ในกลุ่มพิมพ์ `@ai /reset`)

## ความปลอดภัย (ตั้งไว้ให้แล้ว)

- **อ่านอย่างเดียว:** AI แก้ไขหรือลบข้อมูลในชีตไม่ได้เลย
- **แท็บต้องห้าม:** `Device_Map`, `Device_Log` (มีโทเคนกล่องปุ่ม) AI มองไม่เห็นเลย ถึงจะถามในแชทส่วนตัวก็ตาม
- **แท็บที่ห้ามเปิดในกลุ่ม:** `Staff` ถามในแชทส่วนตัวของคุณยังอ่านได้ แต่ถามในกลุ่มจะอ่านไม่ได้
- คอลัมน์ที่หัวมีคำว่า token / password / รหัสผ่าน จะแสดงเป็น `***`
- **ความจำเก็บแยกไฟล์ส่วนตัว** (`AI_Memory — เลขา AI (ส่วนตัว)`) ไม่สร้างแท็บเพิ่มในไฟล์โรงงาน
  คนที่เข้าไฟล์โรงงานได้จึงไม่เห็นแชทส่วนตัวของคุณ และ AI ไม่ไปกวนตัวหาแท็บของระบบบอร์ด
- ตอบด้วย reply เท่านั้น ไม่ใช้ push ข้อความ AI จึงไม่กินโควตาข้อความรายเดือนของ LINE OA
- AI พังยังไงก็ไม่ลากโค้ดเดิมพังตาม (ห่อ try/catch แยกไว้)

## ติดตั้ง (ประมาณ 10 นาที)

### 1) ขอคีย์ Gemini
เข้า [Google AI Studio](https://aistudio.google.com/apikey) แล้วกด **Create API key**

> ⚠️ ถ้าใช้คีย์ฟรี (ไม่ผูกบัตร) Google อาจนำข้อมูลที่ส่งเข้าไปไปใช้ปรับปรุงบริการ
> เพราะจะส่งข้อมูลโรงงานเข้าไป แนะนำให้เปิด Billing ของโปรเจกต์ใน AI Studio (paid tier)
> แล้วตั้งงบรายเดือนไว้ รุ่น Flash ราคาถูกมากสำหรับปริมาณแชทแบบนี้

### 2) เพิ่มไฟล์ AiAgent
1. เปิดโปรเจกต์ Apps Script ของบอทตัวที่มี `doPost` / `routeEvent_` (ไฟล์ `Reminder_Code`)
2. กด **＋ → Script** แล้วตั้งชื่อว่า `AiAgent`
3. ก๊อปปี้โค้ดทั้งหมดจาก [`AiAgent.gs`](AiAgent.gs) ไปวาง แล้วกด Save

### 3) แก้โค้ดเดิม 1 บรรทัด
ใน `Reminder_Code` ให้หาท้ายฟังก์ชัน `routeEvent_` แล้วเพิ่มบรรทัดที่มี ← ตามนี้

```js
  // ── ข้อความปกติ : ไม่ทำอะไรเลย ──
  if (typeof AiAgent_handle === "function" && AiAgent_handle(ev)) return;   // ← เพิ่ม
  return;
}
```

### 4) ใส่ค่าใน Script Properties
ไปที่ **Project Settings (⚙️) → Script Properties → Add script property**

| Property | ค่า |
|---|---|
| `GEMINI_API_KEY` | คีย์จากข้อ 1 |
| `AI_OWNER_USER_ID` | userId ของคุณ: พิมพ์ `/id` ในแชทส่วนตัวกับบอท โค้ดเดิมจะตอบ `U...` กลับมา |

ไม่บังคับ:

| Property | ใช้ทำอะไร |
|---|---|
| `AI_GROUP_IDS` | groupId ที่ให้ใช้ `@ai` ได้ คั่นด้วย `,` ถ้าไม่ใส่จะใช้ `LINE_GROUP_ID` กลุ่มเดิม |
| `GEMINI_MODEL` | ค่าเริ่มต้นคือ `gemini-flash-latest` รัน `AiAgent_listModels` เพื่อดูรุ่นที่ใช้ได้ |
| `AI_GROUP_PREFIXES` | คำนำหน้าในกลุ่ม ค่าเริ่มต้นคือ `@ai,/ถาม,/ai` |
| `AI_BLOCKED_TABS` | แท็บที่ห้าม AI อ่านเพิ่มเติม (เพิ่มจากค่าเริ่มต้น ไม่ได้แทนที่) |
| `AI_GROUP_BLOCKED_TABS` | แท็บที่ห้ามเปิดในกลุ่มเพิ่มเติม |
| `AI_SHEET_ID` | ให้อ่านไฟล์อื่น ถ้าไม่ใส่จะใช้ไฟล์เดียวกับ `/deal` |
| `AI_OFF` | ใส่ `1` = ปิด AI ทันทีโดยไม่ต้อง deploy ใหม่ |

### 5) ทดสอบในหน้า editor ก่อน (ยังไม่กระทบ LINE)
1. เลือกฟังก์ชัน `AiAgent_setup` แล้วกด **Run** ดู Execution log ว่าทุกบรรทัดขึ้น ✅
   (รันครั้งแรกจะสร้างไฟล์ความจำให้ใน Drive ของคุณ)
2. เลือก `AiAgent_test` แล้วกด **Run** มันจะถามว่า "ตอนนี้ในแผนมีงานค้างกี่รายการ" ให้ดูคำตอบใน log
   - ถ้าเจอ error `404 ... model` ให้รัน `AiAgent_listModels` แล้วเอาชื่อรุ่นที่ได้ไปใส่ `GEMINI_MODEL`

### 6) Deploy ทับตัวเดิม (สำคัญ: URL ต้องไม่เปลี่ยน)
**Deploy → Manage deployments → ✏️ (Edit) → Version: New version → Deploy**

> ห้ามกด "New deployment" เพราะจะได้ URL ใหม่ แล้ว Webhook ใน LINE จะชี้ไปตัวเก่า

จากนั้นทักบอทในแชทส่วนตัว แล้วลองพิมพ์ `@ai สวัสดี` ในกลุ่ม

## ปรับความรู้ของ AI
ตัวแปร `AI_FACTORY_NOTES` ด้านบนของ `AiAgent.gs` คือข้อมูลพื้นฐานที่ AI รู้ (ขั้นตอนงาน ความหมายของสถานะ แท็บไหนเก็บอะไร)
ยิ่งเขียนละเอียด AI ยิ่งเลือกแท็บและคอลัมน์ได้ถูก

## ทางเลือก: แก้ผ่าน clasp + Claude Code
```bash
npm install -g @google/clasp
clasp login
# เปิด Apps Script API ก่อนที่ https://script.google.com/home/usersettings
clasp clone <SCRIPT_ID>        # Project Settings → IDs → Script ID
# วาง AiAgent.gs ลงโฟลเดอร์นี้ แก้ routeEvent_ แล้ว
clasp push                     # ⚠️ push จะเขียนทับทั้งโปรเจกต์ ถ้าเพิ่งแก้ในเว็บ ให้ clasp pull ก่อนทุกครั้ง
```
จากนั้นทำข้อ 6 (deploy ทับตัวเดิม) ในหน้าเว็บ

## ข้อจำกัดที่ควรรู้
- Apps Script อ่าน header `x-line-signature` ไม่ได้ จึงยืนยันไม่ได้ว่าคำขอมาจาก LINE จริง (บอทเดิมก็มีข้อจำกัดนี้อยู่แล้ว)
  อย่าแชร์ URL ของ web app ให้ใคร แม้มีคนยิงคำขอปลอมเข้ามา คำตอบก็ส่งกลับผ่าน LINE ไม่ได้ไปถึงคนยิง
- AI ตอบเฉพาะข้อความตัวอักษร ยังไม่อ่านรูปหรือสลิป
- ค้น/นับย้อนจากท้ายแท็บได้ไม่เกิน 5,000 แถวต่อครั้ง แท็บที่ใหญ่กว่านั้นจะแจ้งว่านับเฉพาะส่วนล่าสุด
